# Insight of the Functional structure of the vegetation using pollen data

## Overview
This GitHub project is associated to the research article "*Functional signatures of surface pollen and vegetation are broadly similar: good news for past reconstructions of vegetation* published in *Journal of Biogeography* in 2025 (Dugerdil et al., 2025a).
